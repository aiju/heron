## The boards

A double Eurocard takes about 70 area units: a unit is a DIP-20's slot on a board soldered by hand, and wider parts take more (the table at the end). *Tax* is what a board carries only because it is a board of its own: its slice of the control store, its µPC receivers, its clock buffer, and its drivers and receivers on the backplane (some of which also serve as an operand's multiplexer).

## Delays

A tick is 19.86 ns (50.35 MHz). Every microcycle keeps 2 ns beyond its longest path. Worst-case figures, ns:

|---|---:|---|
| `cq` | 7.1 |  |
| `oe` | 6.7 |  |
| `buf` | 3.9 |  |

| `w` | 2 |  |
| `su` | 1.5 |  |
| `sk` | 2.5 |  |
| `sk1` | 1 |  |
| `gal` | 7.5 |  |
| `sram` | 12 |  |
| `flash` | 55 |  |
| `xbar` | 10 |  |

| XD | 15.9 | a value driven onto the backplane, at logic on another board |
| X | 19.8 | the same through a driver of its own |

The flash loop makes the floor 5 ticks with 55 ns flashes; with 45 ns ones, or a control store in SRAM, nothing in the control store stops at 4.
