# RFC 0029: register banks, the tables

Generated by `heron fen banks --write` (studies/fen/banks.py); what the
numbers say is in [register-banks.md](register-banks.md).

## What the operations cost

Cycles, timed in a bare system-mode program on the simulator.

| Operation | D16-overlap | D32-separate |
|---|---:|---:|
| save a bank's 16 registers to memory (MFUR, STM) | 87 | 88 |
| load a bank's 16 registers from memory (LDM, MTUR) | 87 | 90 |
| save r8-r15 | 44 | 45 |
| load r8-r15 | 44 | 46 |
| BCOPY a message (r0-r7) between banks | 25 | 26 |
| copy a message memory to memory (LDM, STM) | 38 | 39 |
| no banks: save and restore r0-r7 on the stack | 36 | 37 |
| no banks: save and restore r8-r14 on a switch | 32 | 33 |
| MFUR a user register | 3 | 3 |
| load a user register from a frame in memory | 5 | 6 |

Besides moving registers, a kernel that shares banks would spend about 50 cycles a miss
choosing the victim (15 with one user bank) and 5 a switch marking the bank used
(estimates).
