Heron · Egret desktop

A Smalltalk-style desktop written in Egret, running on a simulated Heron draft 1b minicomputer, cycle by cycle, at the speed you choose.

      Using it
      
    
        
  • Click the desktop for the menu: Workspace, Transcript, Browser, Egretica, Gadgets, the clock. Right-click a window for its own menu.
    • 
        
  • Drag a title bar to move a window; its corner resizes it; the box closes it.
    • 
        
  • In a Workspace, put the cursor on a line (or select some) and press Ctrl+D to do it, Ctrl+P to print it. Cmd works too.
    • 
        
  • Gadgets (on the menu) is a table of parts with cartoon physics. Run it, take parts from the bin, drag them about. Right-click a part and Edit its class: change its colour, gravity or bounce and press Ctrl+D, and it changes as it runs. New part… makes a new kind.
    • 
        
  • Egretica (on the menu) is a little computer algebra system after Mathematica. Type a line at the bottom and press Return: D[x^2 Sin[x], x], Integrate[1/(x^3 + 1), x], Solve[x^2 - x - 1 == 0, x], Series[Tan[x], {x, 0, 7}], N[Pi, 50], Plot[{Sin[x], Cos[x]}, {x, 0, 2 Pi}]. Help[] lists the rest; right-click it for examples. At 3 MHz a line takes a second or two: try 12 or 48 MHz.
    • 
        
  • In the Browser, double-click a class (or a method) to open it in a Workspace, change it, and run it again with Ctrl+D. Running windows pick up the change.
    • 
        
  • Restart starts from the desktop just booted; Cold boot starts the machine from nothing, compiling the whole desktop as it boots. A Workspace loop that never ends needs a Restart.
